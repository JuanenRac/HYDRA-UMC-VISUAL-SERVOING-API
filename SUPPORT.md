# Support Information 🛠️ (HYDRA-UMC-VISUAL-SERVOING-API)

Thank you for using the HYDRA-UMC-VISUAL-SERVOING-API! Here is how you can get help:

## 📺 Video Tutorials & Demos
The best way to understand how to implement visual servoing loops is through our official YouTube channel:
[youtube.com/@electrohobby3d](https://youtube.com/@electrohobby3d)

## ✉️ Direct Technical Inquiries
For industrial licensing, kinematic consulting, or specific technical blockers:
Email: `electrohobby3d@gmail.com`

## 🐛 Bug Reports
If you found a real error in the math logic or SPI integration, please open a **GitHub Issue** in this repository. 
*Please search existing issues before opening a new one.*

## ❌ What is NOT support?
- We do not provide support for non-standard robotic kinematic chains without consulting.
- Please do not use Issues for "How to" questions.
